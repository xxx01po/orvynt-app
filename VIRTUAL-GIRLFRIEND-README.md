# Virtual Girlfriend AI — Dark Natural

Первая мобильная версия интерфейса виртуальной собеседницы «Аня».

## Что уже работает
- Адаптивный интерфейс для мобильного Safari.
- Главный экран с CSS-портретом-прототипом и базовыми idle/breathing-анимациями.
- Навигация между главной, чатом, памятью и настройками.
- Переключение эмоций на экране.
- Настройка черт характера и сохранение локальных настроек в `localStorage`.
- Отправка сообщений в интерфейс предпросмотра с явным обозначением, что ИИ ещё не подключён.
- Очистка локальных настроек.

## Что пока НЕ подключено
- Настоящая языковая модель и серверный backend.
- Авторизация и серверная база данных.
- Долговременная облачная память и синхронизация между устройствами.
- Реальное распознавание речи, синтез голоса и синхронизация губ.
- Фотореалистичный 3D-аватар. Текущий CSS-портрет — временная стилизованная заглушка, не финальная внешность.
- Публикация приложения.

## Архитектурный следующий этап
1. Перенести frontend в React + TypeScript + Vite.
2. Добавить backend API с серверным хранением ключей.
3. Подключить модель через адаптер провайдера, ограничение частоты запросов и лимиты расходов.
4. Добавить PostgreSQL (пользователи, сообщения, сводки и управляемые пользователем факты памяти).
5. Подключить голосовые сервисы и отдельный модуль состояния эмоций.
6. Подготовить деплой и проверить на iPhone Safari.

## Просмотр
Откройте `index.html` в браузере или запустите GitHub Codespaces для дальнейшей разработки. Это прототип интерфейса, а не готовое AI-приложение.
